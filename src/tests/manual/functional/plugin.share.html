Share Plugin

Each button opens a platform share URL in a new window. Allow pop-ups for this page, and expect the target site to load with the title and url prefilled.

1. Twitter

Click Share. A twitter.com intent window opens containing the title and url below.

2. WhatsApp

Click Share. An api.whatsapp.com window opens with the title followed by the url.

3. LinkedIn

Click Share. A linkedin.com share window opens.

4. Unknown platform fails quietly

Only twitter, whatsapp and linkedin are supported. Click Share: no window opens and the console logs "Unsupported share platform: facebook".

5. Each button carries its own values

Click Share. The opened url should contain "Second title" rather than the title used above, proving the values are read per element.
