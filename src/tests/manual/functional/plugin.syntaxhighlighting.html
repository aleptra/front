Syntaxhighlighting Plugin

The plugin wraps tokens in <mark> elements. Inspect the code blocks to confirm the marks exist rather than judging by colour alone.

1. Escaped markup

Tags, attribute names and attribute values should each be marked.

<div class="box" hide>Hello</div>

2. JSON

Keys, strings, numbers and booleans should each be marked separately.

{"name":"Front","enabled":true,"version":1,"tags":["ftml","dom"]}

3. Multi line block keeps its line breaks

Indentation and newlines must survive highlighting.

<ul data-iterate="items"> <li data-get="title"></li> </ul>

4. Plain text is left alone

Nothing to tokenise here, so the text should render unchanged and not throw.

just some words

5. Re-highlight after the content changes

Click the button. The block is replaced and highlighted again through onsethtml.
