Clipboard Plugin

Clipboard access needs a user gesture and a secure context, so serve this over http://localhost rather than opening the file directly.

1. Copy the element's own text

Click Copy, then paste somewhere. You should get "copy me".

copy me

2. Paste into a field

Copy any text, then click Paste. The input should receive the clipboard contents.

3. Range mode copies the selection

Select part of the sentence below, then click Copy selection. With clipboard--conf="range:true" on the script tag only the highlighted text is copied. With the current false setting the whole element is copied instead.

Select only these few words and copy them.

4. Chained feedback

Click Copy. The status text updates, confirming the action completed.
