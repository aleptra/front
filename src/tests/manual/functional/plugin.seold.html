Seold Plugin

The plugin collects a name, description and url from the page and injects a JSON-LD structured data block into the document. Inspect the end of <head> or <body> for a script type="application/ld+json" element.

1. Values are collected from the page

The three elements below feed the structured data. Nothing changes visually.

Term: Attribute

Definition: A declarative instruction placed directly on an element.

Reference

2. A JSON-LD block is injected

Run this in the console. Expect one script element whose text contains "Attribute".

document.querySelectorAll('script[type="application/ld+json"]').length
document.querySelector('script[type="application/ld+json"]').textContent

3. Values are readable on the plugin

Run this in the console. Each should match the text above.

app.plugin.seold.nameValue
app.plugin.seold.descValue
app.plugin.seold.urlValue

4. Partial data does not throw

This page provides all three values. Comment out the description element above, reload, and the page should still work with a smaller block.
