Progressbar Plugin

The plugin styles a native <progress> element by injecting pseudo-element rules into a stylesheet with the id pb-<element id>. It reads the color, bgcolor and radius attributes.

1. Colours are applied

The bar should show a red fill on a black track with rounded ends.

2. Independent bars

Each bar keeps its own colours, so this one must stay green on grey.

3. Shade shorthand works

This bar uses bgcolor="black01", so the track should be a light translucent grey rather than solid black.

4. Updating the value keeps the styling

Click the buttons. The fill length changes while the colours stay applied.

5. A stylesheet is created per bar

Run this in the console. All three should be style elements, not null.
