Particles Plugin

Options come from particles--conf on the script element and apply to every container on the page. Each particle is a child element of the container.

1. Particles are created and animate

Forty particles should appear in the box and drift upward continuously.

2. Count matches the config

Run this in the console. Expect 40, matching particles:40 above.

document.querySelector('[particles--load]').children.length

3. Mouse tracking

With mousemove:true, move the pointer across the first box and the particles should react to it. Set mousemove:false on the script tag, reload, and the motion should ignore the pointer.

4. Two independent containers

Both boxes fill with their own particles and animate independently.

5. A collapsed container is harmless

The container below has no height. Nothing should render and the page must not throw.
