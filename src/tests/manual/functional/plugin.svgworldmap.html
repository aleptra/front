Svgworldmap Plugin

The plugin loads a world SVG, injects it into the container and places markers from the svgworldmap--lat, svgworldmap--lng and svgworldmap--label attributes. It needs world.svg to be reachable from the page, so serve this over localhost.

1. Map renders with a marker

The container should hold an svg inside a .svg-world-map wrapper, with a labelled marker over Stockholm.

document.querySelector('#worldmap .svg-world-map')
document.querySelector('#worldmap svg')

2. Drag and zoom

Drag the map to pan it, then use the wheel to zoom. Panning speed follows dragSensitivity in the script config.

3. Fixed marker size

With fixedMarkerSize:true the marker keeps its screen size while zooming. Set it to false, reload, and the marker should scale with the map.

4. Filter markers by tag

svgworldmap-filter declares the groups. Click a button: only markers carrying that tag stay visible. Click it again to clear the filter.

5. A missing world.svg fails quietly

Open this page over file:// so the svg cannot load. The container should stay empty and the page must keep working.
