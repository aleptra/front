1. Type to filter rows

Type "an" in the field. Banana and Mango stay, Apple and Cherry disappear. Clear the field and all four come back.

2. Empty state message

Type "zzz" below. Every row hides and the message appears through filtersearch--onempty. Clear the field and the message hides again.

3. Match count drives a heading

filtersearch--count writes the number of matches into a variable, which if then reads. Type "zzz": the heading hides because the count reaches 0. Clear the field: it comes back.

4. Search a hidden value

Type "citrus". The Lemon row matches on its hidden marker even though the word is not visible in the row.

  • Lemon citrus
  • Apple pome

5. Filter by group

Tick "With value". Only rows whose marker has a value stay visible. Untick to restore.

  • Module row data

6. Reset restores every row

Filter the first list, then click Clear. The field empties, all rows return and focus goes back to the field.
