Geolocalize Module

The browser asks for location permission on load. Allow it for tests 1 and 2, deny it for test 3 (use a private window to be asked again).

Note: geolocalize-get depends on an app.await registry that front.js does not create on its own. The inline script below primes it, which is what the automated test does too. Without it the callback throws when the position arrives.

1. Coordinates fill a variable

Allow location access. The link below should get its href rewritten from {coords} to "latitude,longitude".

Open my position

2. Values are stored on the module

After allowing access, run this in the console. Both should be non-zero numbers.

app.module.geolocalize._latitude
app.module.geolocalize._longitude

3. Denied permission shows the error target

Deny location access. The hidden #geoerror element below should become visible and read "User denied the request for Geolocation" in red.
