Map Plugin

The plugin reads coordinates from map--lat and map--lng on the target element and renders through a provider configured in map--conf. Google and Bing need an API key; OpenStreetMap does not. Without a usable provider the target is queued and stays empty, which is the expected fallback.

1. Coordinates are picked up

Click Render. Run the console line afterwards: the pending target should be this element.

app.plugin.map._pendingTarget

2. A second location

Click Render. The pending target switches to the second box, proving coordinates are read per element rather than globally.

3. Missing coordinates fail quietly

Click Render. The box has no lat or lng, so nothing should render and the page must keep working.

4. No provider configured

Remove map--conf from the script tag and reload, then click any Render button. The target should stay empty without throwing.
