Auth Module

The module reads a JWT from local storage. Use the buttons below to log in with a token that never expires, or with one that is already expired, then reload to see how the attributes react. Attributes are evaluated on load, so reload after changing state.

1. auth-protect removes content when not logged in

Logged out: the box below is removed from the DOM entirely. Logged in: it stays.

Protected content

2. auth-show hides content when not logged in

Logged out: hidden. Logged in: visible.

Visible only when logged in

3. auth-hide hides content when logged in

Logged out: visible. Logged in: hidden. This is the inverse of test 2.

Visible only when logged out

4. An expired token is not valid

Click "Log in (already expired)". The page should behave exactly like logged out: test 1 removed, test 2 hidden, test 3 visible.

5. Globals and claims

Run these in the console while logged in. Expect true, the user object, and "Demo User".

app.globals.get('authenticated')
app.module.auth.getUser()
app.module.auth.getClaim('name')
