Wave Plugin

The plugin slices an image onto a canvas and animates the slices to fake a waving motion. The image url comes from wave--conf on the script element, so this page needs network access.

1. Canvas is created and animates

A canvas should appear inside the box showing the image with a continuous ripple.

2. One canvas per container

Run this in the console. Expect 1 for the box above.

document.querySelector('[wave--load]').querySelectorAll('canvas').length

3. Slice count changes the detail

Set slices:8 in wave--conf and reload. The ripple should look coarse and blocky compared to 40 slices.

4. A missing image renders nothing

With no reachable image the container stays empty and no canvas is created. Point src at a bad url and reload: the page must keep working.

5. A collapsed container is skipped

The container below has no size, so the plugin bails out before creating a canvas. Expect 0 canvases and no error.

document.getElementById('wavecollapsed').querySelectorAll('canvas').length
