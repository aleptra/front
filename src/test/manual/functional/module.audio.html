Audio Module

Drop an audio file at assets/tone.mp3 before running these tests. The module wraps the browser Audio object, so the file has to be reachable.

1. Play a file on click

Click Play. The file should start playing. Nothing visible changes.

2. Two independent sources

Each button plays its own file. Clicking both starts two overlapping sounds.

3. Missing file fails quietly

Click Play. No sound plays and the page keeps working. Check the console for the browser's own media error.

4. Chained with another action

Click Play. The text below changes to "played" and the sound starts.
